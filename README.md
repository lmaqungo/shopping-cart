# Green Finger

Online marijuana dispensary stocked with the most potent produce. 100% organic, grown with love.

## Features

Add to cart  
Apply filters to aid product selection  
Save items for future shopping sessions

## Tech stack

[![Tech Stack](https://skillicons.dev/icons?i=js,html,css,react)](https://skillicons.dev)

## Installation

```bash
git clone git@github.com:lmaqungo/shopping-cart.git
cd shopping-cart
npm install
npm run dev
```
